LITTLE SPROUTS SNACK TRACKER
This is a phone-friendly prototype/PWA shell.

IMPORTANT:
Do not enter real children's names, allergies, or other personal information into this prototype.
It stores data in the browser's local storage and has no secure staff login or shared database.

To publish the prototype:
1. Create a GitHub account.
2. Create a repository.
3. Upload index.html and manifest.webmanifest.
4. In Settings > Pages, publish from the main branch/root.
5. GitHub will give you a github.io web address.
6. On iPhone Safari, open the address, tap Share, then Add to Home Screen.

Before real nursery use, replace local storage with a secure authenticated database and get the nursery's approval/data-protection arrangements in place.
